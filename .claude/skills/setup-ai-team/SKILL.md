# 目的
Claude Code上で動作するAI組織を構築・改善する。

# 作業手順

1. 既存の .claude/agents/ と .claude/skills/ を確認する。
2. README.md を読み、現在の組織構成と設計方針を把握する。
3. ユーザーの要望から、追加・変更すべき役割を整理する。
4. 作業前に変更対象と変更内容を説明する。
5. 承認を得てから必要なファイルを作成・変更する。
6. 既存の部下やスキルとの役割の重複を確認する。
7. 作成したファイルの形式と参照関係を検証する。
8. 変更内容と使い方をREADME.mdに反映する。

# 設計方針

- 部下の性格、判断基準、専門性を明確にする。
- 各部下に独自の役割を持たせる。
- 必要以上に部下やスキルを増やさない。
- 既存ファイルを理由なく上書きしない。
- 不明点があれば、勝手に重要な仕様を決めない。
- 将来の追加・変更が容易な構成を維持する。

# 完了報告

- 作成・変更したファイル
- 各部下の役割
- 利用方法
- 確認した内容と未確認事項
