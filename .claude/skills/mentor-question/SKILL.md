# 目的
保存したノートから一問一答の問題集を作り、ビューアの「一問一答」画面で解けるようにする。
対話式の出題は /mentor-quiz が担当する。このスキルは問題の作成と保存だけを行う。

# 実行手順

## STEP 1：作成条件を確認する
作成の前に、次をユーザーに確認する。
- カテゴリ: 引数があればそれを使う。なければ outputs/mentor/notes/ の既存フォルダ一覧を示して選んでもらう。
- 問題数: 件数を聞く。（目安として10問を提案する）
- カテゴリのノートが存在しない、または空の場合は、その旨を伝えて終了する。

## STEP 2：ノートを読んで問題を作る
outputs/mentor/notes/<カテゴリ>/ のノートを読む。
- 「復習・問題作成用メモ」を中心に使う。「つまずいた点・誤解していた点」も参考にする。
- 問題と答えはノートに書かれた内容から作る。ノートにない事実を答えにしない。
- 補足が必要なときは、解説に「ノート外の補足」と明記する。
- 一問一答にするため、答えは短く（用語、数値、短い一文）する。
- 同じノートに偏らないようにする。

## STEP 3：問題集を保存する
outputs/mentor/quiz/questions/yyyymmdd_カテゴリ.md に保存する。
- outputs/mentor/quiz/questions/ がなければ作成する。
- 同名ファイルがある場合は上書きせず、追記するか別名にするかをユーザーに確認する。
- 機密情報、APIキー、個人情報は書かない。
- 形式は下記を厳守する。ビューアがこの形式を読み取って表示する。

## STEP 4：報告する
保存先と問題数を、2行以内で伝える。ビューアの「ツール」タブの「一問一答」で解けることを添える。

# 問題集の形式

- 各問題は「### 問N」の見出しで始める。
- 項目は「- 問題:」「- 答え:」「- 解説:」「- 出典:」の順に書く。解説と出典は省略してよい。
- 項目の内容が複数行になる場合は、次の行に字下げして続ける。

```markdown
# 問題集：カテゴリ名

- 日付: yyyy-mm-dd
- カテゴリ: 
- 出典ノート: （ファイル名の一覧）

### 問1
- 問題: 
- 答え: 
- 解説: 
- 出典: （ノート名）

### 問2
- 問題: 
- 答え: 
```
