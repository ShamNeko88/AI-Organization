
# AI-Organization

Claude Codeを活用した、複数のAIエージェントによる意思決定支援システム。

現実主義者・理想主義者・批判担当など、
異なる価値観を持つAIを組み合わせ、
多角的な分析と意思決定を行うことを目的とする。

## 1. 目的

- ひとつの視点に偏らない意思決定を支援する
- 異なる価値観を持つAIに意見を出させる
- AIの役割や判断基準を継続的に改善する
- GitHubで構成を管理し、別の環境でも再利用する

## 2. フォルダ構成


## 3. AIエージェント

| 名前 | 役割 | 主な判断基準 |
|---|---|---|
| realist | 現実主義者 | 実現可能性、費用対効果、リスク |
| idealist | 理想主義者 | 創造性、可能性、長期的な価値 |
| critic | 批判・検証担当 | 前提条件、反証、見落とし |

各エージェントの詳細は `.claude/agents/` 内の
Markdownファイルで定義する。

## 4. スキル

### setup-ai-team

AI組織の構築、エージェントの追加、
役割や指示の改善を支援する。

### multi-perspective

複数のエージェントに独立した分析を依頼し、
意見の比較と最終結論の作成を行う。

## 5. 基本的な使い方

Claude Codeを本リポジトリのルートで起動する。

- `/multi-perspective`：複数の視点から課題を分析する
- `/setup-ai-team`：AI組織の構築・改善を支援する

必要に応じて、スキルに議題や追加条件を指定する。

※ 実際の動作には、Claude Codeによる
エージェントの呼び出しが必要。

## 6. 運用方針

- 役割ごとの責任範囲を明確にする
- 既存の設定を確認してから変更する
- 大きな変更はGitのブランチで管理する
- 動作確認後に変更を取り込む
- 機能を増やしすぎず、必要性に応じて拡張する

## 7. 今後の拡張候補

- 技術アドバイザー
- 調査・情報収集担当
- 長期計画・戦略担当
- ファイルや成果物のレビュー担当
- エージェント間の連携方法の改善

## 8. 改善履歴

AI組織の役割、判断基準、運用方法を変更した際は、
変更内容とその理由を記録する。
